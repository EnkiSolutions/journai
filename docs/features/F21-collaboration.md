# F21 — Commentaires, abonnements et notifications

Gérer commentaire, abonnement et notification sur le registre objet.

Source : [spécification](../specification.md).

Dépendances : F03, F11.

## Critères d’acceptation

- [ ] Rattacher les échanges à un vrai objet, gérer réponses et résolution.
- [ ] Gérer abonnements, niveaux de notification et état lu/non lu.
- [ ] Ne notifier que les destinataires autorisés et préserver les droits sur les commentaires des actions partagées.
