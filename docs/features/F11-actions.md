# F11 — Actions, sous-actions et contributeurs

Gérer action, contribution_action et action_constat.

Source : [spécification](../specification.md).

Dépendances : F03, F10.

## Critères d’acceptation

- [ ] Une action a un responsable, une nature, un résultat/critère d’acceptation, des dates et un statut.
- [ ] Gérer contributeurs, rôles et charges prévues/réalisées.
- [ ] Décomposer en sous-actions sans cycle d’ascendance et garder les actions terminées consultables.

## Livraison

- [ ] Code implémenté et vérifié
- [ ] CodeRabbit approuve le dernier SHA sans fil ouvert
- [ ] Reviewer justifie chaque ligne modifiée et valide le certificat
